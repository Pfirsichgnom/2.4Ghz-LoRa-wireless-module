SX1280 2.4 GHz Diversity Transceiver  
This project is my attempt to design a compact, low-power 2.4 GHz transceiver PCB based on two Semtech SX1280 transceiver ICs. The goal is to create a small, affordable, and versatile wireless communication platform that supports experimenting with diversity techniques in both the frequency and spatial domains.  
The design uses two independent transceiver modules, allowing for redundancy through different operating frequencies or separate antennas. Particular attention has been paid to PCB layout, RF signal integrity, power distribution, and electromagnetic compatibility to achieve reliable wireless performance in a compact form factor.  
The project includes the schematics, PCB layout, and associated design files. It also serves as a learning experience in high-frequency PCB design, RF layout techniques, and the practical challenges of building a custom wireless transceiver.
